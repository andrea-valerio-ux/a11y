    How it works

    1. Enter a web addressPick the pages, the widths and the level, and confirm you may test the site.
    2. A machine at GitHub scans itReal Chrome, every page at every width: contrast, keyboard, forms, zoom, motion.
    3. The reports land hereWeb page with screenshots, Excel, Word, PDF, CSV and JSON.
    4. Fix, then scan againEach run keeps its own folder, so progress is easy to show.

    Built on The A11Y Project checklist and the WCAG 2.2 criteria. A scan looks like an ordinary visit to the site being tested.
