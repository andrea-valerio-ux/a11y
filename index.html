Get it running

Once per computer, about a minute. No administrator password is needed.

  1. Unzip the downloadPut the folder anywhere you like, for example in Documents, and keep everything inside it together.
  2. Double-click Install launcherIt is in the launcher folder: Install launcher (Mac).command or Install launcher (Windows).bat. This teaches the button above how to start the scanner.
  3. Come back to this page and press StartThe first time, the browser asks whether to open Accessibility Checklist Scanner. Allow it. From then on the button just works.

Without the launcher

Double-click Start Accessibility Checklist Scanner in the unzipped folder (.command on a Mac, .bat on Windows). It does the same thing as the button.

On a Mac the first time, macOS may say it cannot check the file: right-click it, choose Open, then Open again. On Windows, choose "More info", then "Run anyway".

What you get

The checklist, filled in

Every item of The A11Y Project checklist marked failing, passing, needs a person, or not applicable, with the WCAG criterion, what the rule is about and how to fix it.

A picture of every problem

Each finding carries a screenshot with the element outlined in red, the explanation of what was measured, and the address of the page it was seen on. Reports come as a web page, PDF, Excel, Word, CSV and JSON.
